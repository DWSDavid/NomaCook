---

## Step 1 · 备料 🍅🥚

| UI 元素 | 文案 |
|---|---|
| 步骤标题 | 切番茄,打鸡蛋 |
| 主指令 | 番茄切成小块;鸡蛋打进碗里,加一点盐,搅到颜色均匀 |
| 小贴士 💡 | 番茄块大小尽量接近,炒的时候熟得一样快 |
| 屏幕状态条 | 正在确认:番茄 ✓ 鸡蛋 ✓ 碗 ✓ |
| AI 在看什么(透明化) | 番茄、鸡蛋、碗、案板、刀 |
| 完成的样子 | 番茄成块,蛋液均匀、看不到完整蛋黄 |
| 卡住时它会问 | 「番茄切好、鸡蛋也打匀了吗?」 |
| 完成播报 | 「这一步完成了。下一步,热锅加油,倒入蛋液,翻炒到凝固成浅黄色块状后盛出。」 |

## Step 2 · 炒蛋 🍳(关键步骤)

| UI 元素 | 文案 |
|---|---|
| 步骤标题 | 热锅炒蛋,金黄盛出 |
| 主指令 | 热锅加油,倒入蛋液,翻炒到凝固成浅黄色块状,马上盛出 |
| 小贴士 💡 | 蛋刚凝固就盛出,最后回锅还要再热一次,现在别炒老 |
| 风险提醒 ⚠️ | 蛋液还在流动 → 再等等;出现焦褐色 → 立刻调小火 |
| 屏幕状态条 | 锅内颜色:变黄中 ▓▓▓░░ |
| AI 在看什么 | 锅、油瓶、蛋液、锅铲、盘子(还会分辨油瓶 vs 酱油瓶,不会认错) |
| 完成的样子 | 浅黄色蛋块,没有流动蛋液,已盛出 |
| 卡住时它会问 | 「鸡蛋已经凝固成块并盛出来了吗?」 |
| 完成播报 | 「这一步完成了。下一步,番茄块下锅,翻炒轻压,直到明显软化出汁。」 |

## Step 3 · 炒软番茄 🥄(关键步骤)

| UI 元素 | 文案 |
|---|---|
| 步骤标题 | 番茄下锅,压出汤汁 |
| 主指令 | 番茄块倒进锅里,边翻炒边用锅铲轻压,直到软化出汁 |
| 小贴士 💡 | 用锅铲轻压番茄,出汁更快 |
| 屏幕状态条 | 锅内颜色:变红中 ▓▓▓▓░ |
| AI 在看什么 | 番茄、锅、锅铲 |
| 完成的样子 | 番茄边缘软塌、锅里有明显汤汁,但还保留一些红色块 |
| 卡住时它会问 | 「番茄已经炒软并开始出汁了吗?」(这步节奏慢,它会多等一会儿再问) |
| 完成播报 | 「这一步完成了。下一步,鸡蛋回锅,加盐,拌匀关火,盛盘。」 |

## Step 4 · 合炒装盘 🍽️(关键步骤)

| UI 元素 | 文案 |
|---|---|
| 步骤标题 | 红黄相拥,关火上桌 |
| 主指令 | 鸡蛋倒回锅中,加盐(想吃甜口加一点糖),快速拌匀,关火盛盘 |
| 小贴士 💡 | 回锅后只需快速拌匀,久炒蛋会老 |
| 风险提醒 ⚠️ | 还在锅里加热 = 还没完成,盛到盘子里才算数 |
| 屏幕状态条 | 红黄混合 ✓ · 已上盘 ✓ |
| AI 在看什么 | 番茄、鸡蛋、锅、锅铲、盐、盘子、葱花 |
| 完成的样子 | 红番茄和黄蛋块拌得均匀,已经在盘子里,灶已关火 |
| 卡住时它会问 | 「番茄和鸡蛋已经拌匀、关火并盛盘了吗?」 |
| 完成播报 🎉 | 「全部步骤完成,可以盛盘上桌了。**妈,我会做饭了。**」 |
